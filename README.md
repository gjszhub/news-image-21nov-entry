A newspaper poster summing up Saturday 21 November 2026 in one image:
Russian missiles landing in Poland, the COP31 climate talks running into
overtime in Antalya, the Coalition of the Willing summit in Berlin with
€90bn agreed for Ukraine, and Carlos Alcaraz sweeping his ATP Finals group.

`main.py` (Python 3.13, stdlib only) copies the 1024×1024 poster to
`/output/entry.png`. `compose.py` draws the poster with PIL; running it
twice produces identical bytes.
